# RhoBench 실행 방법

컴퓨터를 껐다 켠 뒤 프로그램을 다시 여는 방법입니다.
**설치는 처음 한 번만** 하면 되고, 그 뒤로는 아래 과정만 반복합니다.

---

## 한눈에 보기

```
Ubuntu 열기 → cd DFT-Workbench → ./scripts/start.sh → 브라우저에서 localhost:8000
```

또는 Windows에서 **`RhoBench-start.bat` 더블클릭** (위 과정을 자동으로 해 줍니다).

---

## 방법 A — 파일 더블클릭 (가장 쉬움)

1. 탐색기에서 프로그램 폴더를 엽니다
2. **`RhoBench-start.bat`** 을 더블클릭합니다
3. 검은 창이 뜨고 서버가 켜집니다 — **이 창은 닫지 마세요**
4. 약 20초 뒤 브라우저가 자동으로 열립니다
5. 비밀번호를 입력하고 접속합니다

브라우저가 먼저 열려 «연결할 수 없음»이 보이면, 5~10초 뒤 **새로고침(F5)** 하면 됩니다.
서버가 아직 준비 중이었던 것뿐입니다.

> 더블클릭으로 켜면 비밀번호를 묻지 않고 **지난번 비밀번호를 그대로** 씁니다.
> 비밀번호를 바꾸려면 아래 방법 B로 실행하세요.

---

## 방법 B — 직접 실행

### 1단계 · Ubuntu 열기

시작 메뉴에서 **Ubuntu** 를 검색해 실행합니다. 이런 화면이 나옵니다:

```
사용자이름@컴퓨터이름:~$
```

`$` 뒤에 글자를 입력하면 됩니다.

### 2단계 · 폴더로 이동

```bash
cd DFT-Workbench
```

폴더 이름이 화면에 나타나면 성공입니다:

```
사용자이름@컴퓨터이름:~/DFT-Workbench$
```

`No such file or directory` 가 나오면 폴더 위치가 다른 것입니다. 아래로 찾으세요:

```bash
cd ~
ls
```

목록에서 `DFT-Workbench` 를 찾아 그 이름으로 `cd` 하면 됩니다.

### 3단계 · 실행

```bash
./scripts/start.sh
```

### 4단계 · 비밀번호

```
접속 비밀번호 (그냥 Enter = 지난번 그대로, 바꾸려면 새로 입력):
```

- **지난번과 같게 쓸 때** → 그냥 **Enter**
- **바꿀 때** → 새 비밀번호를 입력하고 Enter
  (바꾸면 접속 중이던 사람은 모두 로그아웃됩니다)

### 5단계 · 접속 주소 확인

```
================================================================
  RhoBench 시작

  이 컴퓨터에서        http://localhost:8000
  같은 네트워크에서    http://192.168.0.15:8000
  접속 비밀번호        지난번에 쓰던 비밀번호 그대로

  이 창을 닫으면 서버가 멈춥니다. 종료하려면 Ctrl+C.
================================================================

INFO:     Application startup complete.
```

**`Application startup complete`** 가 보이면 준비 완료입니다.

### 6단계 · 브라우저로 접속

주소창에 **`localhost:8000`** 을 입력합니다.
다른 컴퓨터에서 볼 때는 위에 표시된 «같은 네트워크에서» 주소를 씁니다.

---

## 끄는 방법

터미널 창에서 **`Ctrl + C`** 를 누르거나 창을 닫습니다.

계산이 진행 중일 때 끄면 그 작업은 «서버 재시작으로 중단됨»으로 표시됩니다.
결과 화면의 **재시도** 버튼으로 다시 돌릴 수 있습니다.

---

## 재부팅 후에도 남는 것 / 사라지는 것

| 항목 | 재부팅 후 | 저장 위치 |
|---|---|---|
| 계산 결과 | **남습니다** | `data/jobs.json` |
| 접속 비밀번호 | **남습니다** | `data/access.json` (해시) |
| 물질 보관함 · 용매 라이브러리 | **남습니다** | 브라우저 |
| 비교 지표 · 레이더 축 설정 | **남습니다** | 브라우저 |
| 로그인 상태 | 풀립니다 | 서버 메모리 |
| WSL2 · PySCF 설치 | 그대로 | — |

로그인만 다시 하면 되고, **설치·계산을 다시 할 필요는 없습니다.**

## 문제가 생겼을 때

| 화면에 보이는 것 | 원인 | 해결 |
|---|---|---|
| `No such file or directory` | 폴더 이름이 다름 | `cd ~` 후 `ls` 로 폴더 이름 확인 |
| `Permission denied` | 실행 권한 없음 | `chmod +x scripts/start.sh` 후 다시 실행 |
| `ModuleNotFoundError: pyscf` | 설치가 덜 됨 | `./scripts/setup.sh` (이미 된 단계는 건너뜁니다) |
| `Command 'uvicorn' not found` | `uvicorn`이 PATH에 없음 | `python3 -m uvicorn server.main:app --host 0.0.0.0 --port 8000` — 안내되는 `sudo apt install uvicorn`은 **다른 패키지**입니다 |
| `Address already in use` | 서버가 이미 켜져 있음 | 브라우저만 열면 됩니다. 새로 켜려면 `pkill -f uvicorn` 후 재실행 |
| 브라우저에 «연결할 수 없음» | 서버가 아직 준비 중 | 터미널에 `Application startup complete` 가 뜬 뒤 새로고침 |
| 비밀번호가 틀리다고 나옴 | 지난번과 다른 값 입력 | 실행할 때 Enter만 눌러 지난번 것을 유지하세요 |
| 다른 PC에서 접속 안 됨 | 방화벽 | Windows 방화벽에서 8000 포트 허용 |
| 계산이 매우 느림 | WSL2 메모리 부족 | `C:\Users\<이름>\.wslconfig` 에 `[wsl2]` / `memory=12GB` 추가 후 PowerShell에서 `wsl --shutdown` |

## 시연 전 점검

```bash
python -m pytest tests/ -q          # 단위 테스트 (약 5초)

```

## 다른 컴퓨터에서 쓰기 (USB 이동)

### 만들기 (현재 컴퓨터에서 한 번)

```bash
cd ~/DFT-Workbench
./scripts/make_usb.sh
```

`RhoBench-USB` 폴더가 만들어집니다 (약 175 MB). 이 폴더를 통째로 USB에 복사하세요.

담기는 것 — 소스 · 설치 파일(wheel) · 설치 스크립트 · 안내문.
**계산 결과(`data/`)와 가상환경(`.venv/`)은 제외됩니다.**

### 대상 컴퓨터에서 설치 (한 번만)

```bash
cd /mnt/d/RhoBench-USB      # USB 가 D: 드라이브인 경우
./설치.sh
```

인터넷 없이 설치됩니다. 설치 위치는 USB가 아니라 내장 디스크(`~/RhoBench`)입니다 —
USB는 느리고 파일시스템 제약이 있어 그대로 실행하면 문제가 생깁니다.

### 실행

```bash
cd ~/RhoBench
./scripts/start.sh
```

### 조건

| 항목 | 요구사항 |
|---|---|
| 운영체제 | **Ubuntu(WSL 포함) 또는 Linux** |
| Python | USB를 만든 컴퓨터와 **같은 버전** (예: 3.11) |
| 인터넷 | 불필요 |

**PySCF는 네이티브 윈도우를 지원하지 않습니다.** 윈도우라면 WSL을 먼저 설치하세요
(관리자 PowerShell에서 `wsl --install`).

Python 버전이 다르면 오프라인 설치가 실패합니다. 그때는 인터넷을 연결하고
`.venv/bin/pip install -r requirements.txt` 로 설치하세요 — 설치 스크립트가 이 안내를
출력합니다.

### 계산 결과 옮기기

결과는 설치 폴더의 `data/`에 쌓이며 USB에는 들어 있지 않습니다.
옮기려면 `data/` 폴더를 직접 복사하세요.
