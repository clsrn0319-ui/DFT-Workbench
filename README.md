# 바인더 분자 물성 · DFT 워크벤치 (BINDER SCREENING)

「바인더 분자 물성·DFT 워크벤치 통합 기획서 v4.0」을 기준으로 구현한 웹 프론트엔드 프로토타입입니다.
사용자가 물질을 등록하고 특징을 정리한 뒤, 환경·용매·온도에서 구조를 최적화하고, 전기화학 안정성과
전자구조 DFT 결과를 다른 물질과 비교하는 연구용 워크스페이스입니다.

## 화면 구성 (기획서 3.2 정보 구조)

| 좌측 메뉴 | 구현 내용 |
|---|---|
| **대시보드** | 등록 물질·공개 계산·진행 작업 요약, 최근 본 물질, 빠른 실행, 서버 상태 (DASH-01~04) |
| **물질 보관함** | 이름/CAS/태그/SMILES 검색, 카드·표 전환, 편집·삭제(영향 안내), 준비/계산 상태, 비교 체크박스, descriptor 완료도. 새 물질 등록: 이름·CAS→SMILES 검색(내장 사전, CAS 확인숫자 검증), SMILES 직접 입력, 일괄 등록 (LIB-01~07, 4.2.2~4.2.4) |
| **분자 물성** | 상단 식별 영역, 구조 자리, 관찰→해석→계산 권고→주의 4계층, 작용기·경향 카드, 16 descriptor 7그룹 상태, 외부 참고(MPcules) 탭, 이력 (4.3, 12장) |
| **구조 최적화 · DFT** | 환경 유형 4종·용매·온도·분위기·계산 구조·최적화 수준·계산 목적의 간편 설정 + 접힌 "전문 계산 설정"(전하/다중도/conformer/엔진/함수/기저/SCF), 자동 처리 경고, 작업 상태·로그 (4.5) |
| **용매 라이브러리** | 단일/혼합 용매 CRUD, 편집 시 버전 증가, 약어 변경 시 혼합 프리셋 동기화, 삭제 영향 안내 (SOLV-01~06) |
| **DFT 계산 결과** | ★고정 물성 상단 → 전압 범위 막대(0~6 V) → HOMO/LUMO 공통축 → VIP/VEA·결합에너지 카드 → 계산 조건·validation → 이전 이력 → 결과 패키지 JSON(부록 B 형식) (4.6) |
| **물질 비교** | PUBLISHED 결과만 최대 8개, 조건 불일치 경고, 공통축 range 차트, 고정(★) 물성 최상단 비교 표, 물성 지문 레이더, 외부값 점선 오버레이+출처 배지 (4.7, 14.3) |
| **물성 사전** | 부록 D의 16 descriptor + D.1 권장 항목을 7그룹으로 정의·단위·주의와 함께 제공, ★ 고정 동기화 |
| **시각화 · 계정** | 순백+딥 틸+앰버 기본 테마, 배경/카드/강조/pin/차트 series 8색/MEP 색 사용자 설정, 라이트·다크·고대비, 색각 친화 preset, WCAG 대비 검사, Theme JSON export/import (14장) |

## 결과 데이터 정책 (기획서 13.2)

작업 상태는 `QUEUED → RUNNING → VALIDATING → PUBLISHED | NEEDS_REVIEW | FAILED`로 진행하며,
**validation PASSED + PUBLISHED 결과만 수치를 표시**합니다. 그 외 상태는 숫자 없이 상태·사유·재시도
경로만 보여줍니다. 물성 고정(★)은 결과 상단·비교 표·레이더 축에 동기화됩니다.

## 프로토타입 범위

현재 계산은 `src/engine/mockDft.ts`의 **브라우저 내 결정론적 모의 엔진**이 수행합니다(동일 입력 → 동일
결과). 기획서 13장의 실제 백엔드(FastAPI + PostgreSQL + Redis/Celery + RDKit/xTB/PySCF/CP2K) 연동 시 이
모듈과 `store.tsx`의 큐 시뮬레이션을 API 클라이언트로 교체하면 화면은 그대로 동작합니다. 저장은
localStorage(중앙 DB 대체)입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 미리보기
```

기술 스택: Vite + React 18 + TypeScript, 외부 차트 라이브러리 없이 SVG 차트 직접 구현.
